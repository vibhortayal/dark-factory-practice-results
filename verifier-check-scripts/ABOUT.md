# The Verifier's own check scripts from this run (added for the archive)

These are the check lists and scripts the Nightshift Verifier seat wrote during Run 5, for stages 1 to 4. During the run they lived outside the result repository, in `band-work/verifier/`. They were copied here unchanged for the archive on 2026-10-03; until then they sat in a separate branch, `nightshift-run-5-verifier-checks` (commit `ae9cb89`), which this folder replaces.

They were also used after the run, on the demo VM, to compare the apps built by Runs 2, 3, 5 and 6 against the same 900 stage-1 checks.
